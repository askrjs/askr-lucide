# Published 0.4 icon inventory

Enumerated from the installed 0.4.0 declarations on 2026-10-09. Each row records
both the root named export and the wildcard-resolved per-icon path. Every KEEP
has the same concrete catalog contract: this glyph is displayed by the explicit
website icon browser in `website/src/pages/docs/lucide-icons.ts`. Named component
imports let applications select that glyph; its per-icon path avoids loading the
2,031-module root catalog in development or a bundler without tree shaking.
The generated artifact check verifies that the wildcard exposes exactly these
pinned icon modules. Private helpers stay outside that directory.

The four helper/type decisions and metadata entrypoints are recorded in the
[contract review](./0.5-contract-review.md). No public symbol is left undecided.
