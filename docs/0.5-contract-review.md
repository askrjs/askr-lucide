## Export decisions and migrations

| Entrypoint / symbol                            | Decision | Concrete contract or migration                                                                                                                                                                                                                  |
| ---------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.`                                            | KEEP     | Named glyph components used by CLI starters, examples, Destroyer, and the website glyph browser.                                                                                                                                                |
| All 2,031 root icon components                 | KEEP     | Each glyph is rendered by the explicit website catalog; complete per-name decisions are in the icon inventory.                                                                                                                                  |
| `./icons/*` and all 2,031 resolved glyph paths | KEEP     | Documented direct imports avoid loading the entire root catalog during development; AGENTS.md requires preserving tree-shakeable icon paths. The installed matrix resolves every path and the artifact check permits only pinned glyph modules. |
| `createIcon`                                   | MOVE     | Private generated-data adapter; no sibling production import. Author custom SVG children through core `IconBase`.                                                                                                                               |
| `IconNode`                                     | MOVE     | Private validated Lucide definition type; no sibling production import. Custom components use core `IconBase` and SVG JSX.                                                                                                                      |
| `IconProps`                                    | REMOVE   | Duplicate of core `@askrjs/askr/foundations/icon`; the two startkit component imports are migrated in CLI PR [#172](https://github.com/askrjs/askr-cli/pull/172), merged as `74ea2de`.                                                          |
| `IconSizeToken`                                | REMOVE   | Duplicate core size token type; import it from `@askrjs/askr/foundations/icon`. No sibling production import.                                                                                                                                   |
| `./package.json`                               | KEEP     | Installed manifest and peer compatibility tooling; real packed consumer reads it.                                                                                                                                                               |
| `./capabilities.json`                          | KEEP     | Package capability metadata consumed by CLI tooling; real packed consumer reads it.                                                                                                                                                             |

Root helper/type exports shrink from four to zero; glyph components and paths
are intentional supported contracts. There is no safe catalog-wide cut: each
name selects a distinct advertised glyph, and direct paths satisfy a documented
module-loading constraint. No compatibility shim is retained. See the
[complete icon inventory](./0.5-icon-inventory.md) for every published icon pair.

Workspace search covered fetched package sources, CLI templates, examples,
Destroyer, website source and documentation. The only production helper/type
imports were `IconProps` in CLI startkit app-sidebar and stat-card. Private
factory tests retain source imports. The website's generated 0.4 API snapshot
must be regenerated against coordinated candidates before API #41 closes.
